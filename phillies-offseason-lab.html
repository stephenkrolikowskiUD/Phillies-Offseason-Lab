Inside the model (2026 Statcast + Roster Lab)

Data Pipeline Architecture: Player plate-discipline, contact quality, fielding (Outs Above Average), and relief pitching metrics are extracted directly from 2026 MLB Baseball Savant Statcast leaderboards via a custom Google Colab Python pipeline (pybaseball).

Fit Score Formula: Each slider dynamically weights a 0–100 percentile rating across Plate Discipline (low O-Swing% + high Z-Contact%), Outfield Defense (OAA) or Reliever Stuff (Whiff% + K-BB%), and Buy-Low Value (the underperformance gap between expected Statcast metrics xwOBA / xERA and surface wOBA / ERA).

Team Projections: Baseline payroll starts at $246.8M against a $280.0M luxury-tax scenario target ($33.2M spending room). Each added hitter replaces a 450-PA high-chase (32.8%) baseline slot in a 6,200-PA offense. Each added reliever replaces 55 innings of 4.12 xERA relief work in a 580-IP bullpen.
