# The Front Office — Philadelphia Phillies 2027 Offseason Statcast Lab Live Demo: https://stephenkrolikowskiud.github.io/Phillies-Offseason-Lab/ Interactive MLB front-office roster and luxury-tax decision workbench built by Stephen Krolikowski. Powered by a live 2026 Baseball Savant Statcast Python (pybaseball) pipeline in Google Colab, this tool models how low-chase (O-Swing%) position players, positive Outs Above Average (OAA) outfielders, and buy-low xERA/Whiff% relief pitchers impact the Phillies' 2027 Competitive Balance Tax payroll, team chase rate, outfield defense, and bullpen xERA in real time.
